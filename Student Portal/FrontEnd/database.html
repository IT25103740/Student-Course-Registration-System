📂 How to Open the Database File
Option 1 — Text Editor
Open university.db.json in your project root folder with any text editor: VS Code, Notepad++, IntelliJ IDEA, or even plain Notepad.
Option 2 — JSON Viewer (Online)
Copy the JSON from the JSON View tab and paste it into jsonformatter.curiousconcept.com for a collapsible tree view.
Option 3 — VS Code Extension
Install the JSON Viewer extension in VS Code to get a collapsible, syntax-highlighted view of the database file.
Option 4 — Export CSV
Click Export CSV above to download a spreadsheet file you can open directly in Excel or Google Sheets.
